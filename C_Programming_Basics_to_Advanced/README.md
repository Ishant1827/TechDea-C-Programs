HOW TO COMPILE
Using GCC:
    gcc filename.c -o program

Run:
    Windows:
        program.exe
    Linux/macOS:
        ./program

NOTE
Each source file contains comments explaining the important logic.
Some programs using math.h may require:
    gcc filename.c -o program -lm

Practice the programs in folder order for a gradual learning path.
